# 👋 Olá, eu sou o Erik Lisboa!

### Software Development Analyst | Back-End Developer Java

Sou Desenvolvedor Back-End com experiência no desenvolvimento de soluções para o setor financeiro e de pagamentos, atuando com **Java, Spring Boot, microsserviços, APIs REST e arquitetura distribuída**.

Atualmente trabalho como **Software Development Analyst na Getnet**, contribuindo para uma plataforma global de pagamentos utilizada na América Latina e Europa, com foco em **escalabilidade, segurança, alta disponibilidade e tolerância a falhas**.

Tenho experiência com processamento e orquestração de fluxos financeiros envolvendo **cartões, Pix e boletos**, integrações assíncronas, testes automatizados, conteinerização e pipelines de CI/CD.

🎓 Formado em **Análise e Desenvolvimento de Sistemas pelo Instituto Federal da Bahia (IFBA)**.
